# Сменная экипировка Алдара и интеграция с Mixamo

Поскольку источник света — **поясной сосуд для углей (`Ут-һауыт`)** — закреплён на ремне у бедра, обе руки Алдара всегда свободны. Базовая модель Алдара загружается в Mixamo **с пустыми руками**, а все предметы подгружаются в Three.js отдельными `.glb` файлами в кости скелета.

---

## 1. Таблица точек крепления экипировки (`Sockets`)

| ID ассета | Предмет | Кость в Стойке 1 (Кылыс + Щит) | Кость в Стойке 2 (Лук) | Логика в Three.js |
|---|---|---|---|---|
| `eq_ember_vessel` | **Ут-һауыт** (Поясной сосуд для углей) | `mixamorigHips` (слева спереди) | `mixamorigHips` (слева спереди) | В Главе 3 (Зона 2) скрывается (`visible = false`), так как отдаётся Азамату. Содержит внутри `PointLight`. |
| `eq_kylys` | **Ҡылыс** (Отцовская сабля) | `mixamorigRightHand` | `mixamorigHips` (в ножнах слева) | При переключении на лук переносится из правой кисти в узел ножен. |
| `eq_kalkan` | **Ҡалҡан** (Круглый щит) | `mixamorigLeftForeArm` | `mixamorigSpine2` (за спиной) | Крепится к предплечью (`LeftForeArm`), чтобы кисть оставалась свободной. |
| `eq_bow_yaya` | **Йәйә** (Сложносоставной лук) | `mixamorigSpine2` (за спиной) | `mixamorigLeftHand` | Тетива рисуется процедурным `THREE.Line` между рогами лука и пальцами правой руки. |
| `eq_quiver` | **Һаҙаҡ** (Колчан со стрелами) | `mixamorigHips` (справа у бедра) | `mixamorigHips` (справа у бедра) | Содержит до $8$ дочерних мешей стрел (`arrow_01..08`), чья видимость равна `player.arrows`. |
| `eq_arrow_hand` | **Уҡ** (Стрела в руке) | Скрыта (`visible = false`) | `mixamorigRightHand` | Видна только при натяжении тетивы; по нажатию `[F]` на наконечнике зажигается партикл огня. |

## 2. Полный список анимаций Mixamo (15 клипов)

1. `Sword And Shield Idle` — стойка на месте.
2. `Sword And Shield Walk` / `Run` — шаг и бег.
3. `Crouching Idle` — осмотр следов и разжимание капкана Сусар.
4. `Sword And Shield Slash 1`, `Slash 2`, `Spin Attack` — 3 удара базовой серии кылыса.
5. `Sword And Shield Power Attack` — тяжёлый выпад кылысом.
6. `Sword And Shield Block Idle` — удержание блока щитом-калканом.
7. `Sword And Shield Impact` — отскок/парирование щитом.
8. `Shield Bash` — таранный удар кромкой щита вперёд и жест для «Вспышки живицы».
9. `Standing Dodge Forward / Backward / Left / Right` — перекаты.
10. `Standing Equip Bow` — смена стойки на лук.
11. `Standing Aim Idle` — прицеливание с луком.
12. `Standing Draw Arrow` — натяжение тетивы ($0.9\text{ с}$).
13. `Standing Aim Walk Forward / Back / Left / Right` — шаг с натянутым луком.
14. `Standing Aim Recoil` — спуск тетивы.
15. `Standing Torch Light` — короткий взмах рукой для пуска беркута Кары (`[R]`).
