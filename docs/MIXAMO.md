# Mixamo: анимации Тимера для среза

> Статус v1.2: в модели 23 клипа. Поставка 1 — idle, idle_combat, run, roll. Поставка 2 — atk_kos, atk_obr, atk_ukol, atk_polu,
> atk_heavy, block, bow_draw, bow_aim, bow_shot, death. Поставка 3 — stance_fwd/back/left/right, hit, throw, drink, pickup, finisher
> (повторный idle_combat совпал с уже имеющимся). Из обязательных не хватает только `walk` (шаг без стойки: чутьё следопыта сейчас идёт клипом бега).
> Из желательных ждут: release (беркут), pull (рывок по аркану), struggle (хватка Шурале), hit_heavy, get_up, parry, atk_dash, turn_left/right, sit_*.
> charge не нужен: замах берётся из atk_heavy.
> Блок лежит в модели, но включится вместе со щитом (см. ниже).
> Сборка тела и одежды: `tools/hero-rig.mjs`. Новые клипы дописываются в готовую модель: `tools/hero-anims.mjs <dir> <имена>`. Проверка: `/#viewer`.
> Как клипы привязаны к игре — раздел «Как клипы играют в игре» внизу.
>
> Было в v0.9: в игре Idle, Unarmed Run Forward и Stand To Roll (кувырок вырезан из середины, 0.85–1.95 с). Остальные состояния — процедурные позы на костях Mixamo.
> Скелет уже есть: дальше качай всё **Without Skin** (файлы в 15 раз меньше). Если сменится базовое тело — один раз With Skin.

Цель: заменить процедурную походку и удары клипами Mixamo. Пружинный слой (взгляд головы, фонарь, накидка) останется поверх клипов.
Названия анимаций в Mixamo — ориентиры: ищи по ключевым словам и выбирай похожее по описанию.

## Шаг 1. Загрузить персонажа

1. mixamo.com → войти через Adobe ID (бесплатно) → **Upload Character**.
2. Mixamo принимает **FBX, OBJ или ZIP** (OBJ + текстуры), GLB не принимает. Скачай ту же модель из генератора в FBX или OBJ (обычно это есть в Meshy/Tripo). Если нет, скажи: подготовлю файл.
3. Автоматический риггер: поверни модель лицом к себе, расставь маркеры — подбородок, запястья, локти, колени, пах.
4. **Skeleton LOD: No Fingers.** Пальцы у сгенерированных моделей обычно слиплись, без них меньше артефактов.
5. Проверь пробную анимацию: если рука проваливается в кафтан, поправь маркеры и повтори.

## Шаг 2. Для каждой анимации

- Отметь **In Place**, если галочка есть. Движение задаёт код, анимация не должна уезжать вперёд.
- Ползунок **Character Arm-Space** чуть вправо, если руки задевают толстый кафтан.
- Остальные ползунки не трогай.

## Шаг 3. Скачать

- **Format: FBX Binary (.fbx)**
- **Skin: With Skin** — только для первой анимации (idle). Для всех остальных **Without Skin**.
- **Frames per Second: 30**, **Keyframe Reduction: none**.
- Назови файлы как в таблице и пришли одним архивом. Конвертацию в игру делаю я.

## Как клипы играют в игре (v1.1)

Код: `src/game/actors/heroAnim.ts`. Три слоя: клипы в микшере → процедурные позы (где клипа нет) → слой верхней части тела.

**Удары не ускоряются целиком, а «гнутся» по фазам.** У игры свои короткие тайминги (Косой 0.34 с, удар на 0.12 с), у клипа — 1.5–3 с.
Время клипа задаётся кодом каждый кадр по прогрессу удара, кусочно-линейно: начало → момент удара → конец окна удара → конец.
Самый быстрый мах кисти в клипе попадает ровно в окно попадания игры (таблица `BLOWS`).

| Удар | Клип | Отрезок клипа, с (начало / удар / конец окна / конец) |
|---|---|---|
| Косой | atk_kos | 0.25 / 0.53 / 0.68 / 0.88 |
| Обратный | atk_obr | 0.50 / 0.80 / 0.95 / 1.12 |
| Укол, Выпад сквозь | atk_ukol | 0.25 / 0.55 / 0.72 / 0.86 — выпад правой рукой, до того как вперёд уходит левая |
| Полумесяц | atk_polu | 0.45 / 0.87 / 1.25 / 1.50 — клип сам делает оборот на 360°, кодовый оборот выключен |
| Замах (держать ЛКМ) | atk_heavy | 0.12 → 0.62 по силе замаха, клинок над головой |
| Рассечение | atk_heavy | 0.62 / 0.78 / 0.90 / 1.35 — продолжает замах |

- **Лук и блок — слой верхней части тела** (Spine и выше): Тимер целится и держит блок на ходу, ноги идут своим клипом.
  Позвоночник привязан к модели, а не к бёдрам: торс смотрит туда же, куда в клипе, как бы ни качались бёдра.
  Стоя на месте, клип берёт и ноги (стойка лучника, стойка блока).
- Лук: bow_draw идёт по натяжению 0..1 (0.1 → 1.0 клипа), на полном натяжении — bow_aim, после каждого выстрела — bow_shot (×1.25), руки возвращаются за последнюю треть.
- Смерть: клип с 0.15 с, ×1.15, без обнуления смещения бёдер — Тимер оседает назад и падает по-настоящему.
- Блок: Sword And Shield Block — вперёд выставлена левая рука под щит. **Решение (v1.2): блок приходит вместе со щитом.** Пока щита нет,
  Shift — только стойка; поза блока и −70% включаются, когда Тимер получает щит (`Player.hasShield`), с отдельным шагом онбординга.

### Поставка 3 (v1.2)

| Состояние | Клип | Как играет |
|---|---|---|
| Стойка (Shift), натяжение лука, глоток на ходу | stance_fwd / back / left / right | Смесь четырёх направлений по шагу относительно взгляда; одна общая фаза (1.7 м на цикл), чтобы по диагонали ноги не путались. В шагах вбок клип разворачивает грудь на ±38° — позвоночник доворачивает её к врагу (−20°, как в шаге вперёд) |

| Добивание (1.0 с) | finisher | 0.10 → 0.85 к удару (0.6 с) → 1.45 |
