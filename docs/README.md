# Документация проекта

Рабочее название: **«Аманат»** (прежнее: «Тело Урала»).
Изометрическая экшн-RPG на Three.js по мотивам башкирского эпоса «Урал-батыр».

| Документ | Содержание |
|---|---|
| [STORY.md](./STORY.md) | Сюжетная канва «Аманат»: поворот, главы, концовки, глава 1 |
| [LEVEL.md](./LEVEL.md) | Уровень «Урман» v2: 12 зон, ритм, маршруты, вода, терновник, завал, секреты |
| [TRACKING.md](./TRACKING.md) | Следопыт: следы, чутьё, знаки, журнал «Следы» |
| [COMPANION.md](./COMPANION.md) | Сусар, куница: капкан в середине главы 1, как ходит, чует невидимых врагов |
| [GDD.md](./GDD.md) | Геймдизайн: столпы, герой, боёвка, прогрессия, структура мира |
| [UI.md](./UI.md) | Интерфейс: референс, шрифты, правила, тексты, экраны |
| [RPG.md](./RPG.md) | Прокачка, снаряжение, лут, боеприпасы |
| [COMBAT.md](./COMBAT.md) | Бой: кылыс, удары, серия, запал, метки |
| [../public/guide/assets.html](../public/guide/assets.html) | **Мастерская Урмана**: понятный HTML-гайд для генерации всех персонажей, экипировки и быта уровня (GPT Image → ракурсы → Hunyuan 3D → Mixamo). Открывается в превью по адресу `/guide/assets.html` |
| [PROMPTS.md](./PROMPTS.md) | Промпты для статики персонажей |
| [MIXAMO.md](./MIXAMO.md) | Список анимаций Тимера и инструкция для Mixamo |
| [EQUIPMENT.md](./EQUIPMENT.md) | Сменная экипировка: что генерировать, как провести через Mixamo, что прислать |
| [LORE.md](./LORE.md) | Лор-библия: мир, персонажи, бестиарий, локации, глоссарий |
| [ART.md](./ART.md) | Арт-дирекшн: стиль, палитра, свет, камера, правила генерации ассетов |
| [TECH.md](./TECH.md) | Техническая архитектура, стек, бюджеты производительности, пайплайн ассетов |
| [ROADMAP.md](./ROADMAP.md) | План вертикального среза по этапам и список нужных ассетов |

Статус: **v0.1, концепт.** Всё, что помечено `[?]`, ещё не решено.
Башкирские слова и имена помечены `[проверить]`, пока их не подтвердил носитель языка.
