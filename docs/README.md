## Ключевые решения версии 2.0 (Шпаргалка)

* **Главный герой:** Беркутчи **Алдар** ($33$ года). Жена — **Айсылу**, старший сын — **Азамат** ($11$ лет, в финале оказывается старым Сэсэном-рассказчиком), нерождённый младший сын — **Торсон**, отец — **Арслан**.
* **Никакого клише с пожаром на старте:** Юрта не сожжена, а поглощена ледяной болотной тиной и изрыта лазами убыров. Под залитым казаном Алдар находит последний тлеющий уголёк.
* **Свет на поясе, обе руки свободны:** Вместо стеклянного фонаря в руке Алдар носит на ремне слева кованый медный сосуд для углей (**Ут-һауыт**). Это освобождает обе руки под стандартные анимации Mixamo.
* **Две боевые стойки:**
  1. **Кылыс + Калкан** (сабля + круглый щит для блока, парирования со снопом искр и таранного удара).
  2. **Лук Йәйә** (высокий урон, жёсткий дефицит стрел — $5\text{–}8$ шт., выдергивание стрел из тел и деревьев, поджиг наконечника от прорези поясного сосуда).
* **Драма куницы Сусар:** Куница — это переселившаяся душа (*йән*) матери Алдара, отдавшей ему своё дыхание жизни (*ҡот*) $30$ зим назад. В $3$-й главе в пещере Шульган-Таш она отдаёт остаток души, чтобы спасти внука Азамата от могильного холода.
