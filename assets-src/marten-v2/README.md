# Сусар / куница — вариант v2

Основная игровая куница. Прежний визуальный вариант удалён.
Характер движения — слегка сказочная текучесть; новый мех не добавлялся.

- `susar_v2.blend` — скелет, скиннинг, запечённые Actions, упакованные текстуры и студийная сцена.
- `susar_v2_curled.png` — поза клубка.
- `qa.json` — отчёт проверки весов, длины лап, непрерывности переходов и зазора от земли.
- `../../public/models/marten_v2_rig.glb` — отдельный игровой экспорт с 45 костями и 14 анимационными образцами.

В Blender выберите арматуру `Susar_V2_Armature` и нужный Action:

| Action | Кадры при 24 fps |
|---|---|
| `Susar_V2_curl_enter` | 0–144: свернуться |
| `Susar_V2_sleep_curled` | 0–96: клубок, голова на хвосте, дыхание |
| `Susar_V2_curl_exit` | 0–144: развернуться |
| Остальные | 0–96: образцы походок, поворотов и поз |

Actions сохранены с Fake User и в отключённых дорожках NLA. Кости распределены по коллекциям Body / Tail / Paws.
Это собственный деформационный риг с кошачьей пластикой, подогнанный под меш; платные готовые риги не использовались.
Для базовой анатомии и постановки лап используется существующий процедурный решатель проекта, а видимый меш имеет отдельный более подробный скелет.

Просмотр основного игрового рига: `/#viewer=marten`. Ссылка `/#viewer=marten_v2` — совместимый псевдоним.
Кнопки «клубок», «свернуться», «развернуться», «скелет», виды сверху/сбоку.
Просмотр использует непрерывный решатель; GLB содержит его запечённые образцы, а не циклы для окончательного монтажа.

Пересборка:

1. `pnpm assets:marten-v2` — проверка и GLB.
2. Выполнить `tools/marten-v2-blender.py` в подключённом Blender — мастер и рендер.

Исходник движения: `src/game/actors/martenRig.ts`. История решения: `docs/ART.md`.
